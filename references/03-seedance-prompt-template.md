# Stage 3｜Seedance 提示词规范（成片提示词文档）

把已确认的分镜表编译为**可直接复制进 `image_to_video` 的逐段标准提示词**，并整理上传图清单与串行工作流。本文件是 `ai-manga-pipeline` 的 Stage 3 必读规范；完整成品格式对照 `references/04-workflow-example.md`。

## 核心认知（贯穿全流程）

**Seedance 每次生成都是独立的，它没有任何记忆。** 上一段里男主长什么样、光从哪边打、女主裙子什么颜色——生成下一段时它全忘了。所以：
1. 每一段都必须把"这一段需要的所有图"一次性传齐；
2. Prompt 里按上传顺序编号引用（图1/图2/图3…）；
3. 图1永远是首帧参考图，决定第 0 秒画面。

## 一、固定资产图清单（全片复用，不要换）

| 编号 | 图名 | 说明 |
|---|---|---|
| **A** | 男主定妆图 | 全片男主脸/发型/服装锚点 |
| **B** | 女主定妆图 | 女主出场段起用，全片女主锚点 |
| **C1~Cn** | 各场景图 | 每个场景一张，标注使用段位 |
| **F0** | 段1首帧构图参考 | 用户准备/生成第一段的 0 秒构图 |
| **F1~Fn** | 各段尾帧截图 | 生成完段 N 后抽最后一帧，作为段 N+1 首帧 |

## 二、每段上传图清单（按顺序传，顺序错了 AI 就认错图）

**通用规则**：每段都用 `image_to_video`，**图1 永远是首帧参考图**（决定0秒画面），后面依次是角色图、场景图。

| 段 | 图1（首帧） | 图2 | 图3 | 图4 |
|---|---|---|---|---|
| 段1 | F0（首帧构图） | A 男主 | C1 场景 | — |
| 段N | F(N-1)（上段尾帧） | A 男主 | B 女主（如有）/ Cx 场景 | Cx 场景（需要时） |

- **为什么图1必须是首帧**：Seedance 会把图1当作视频第0秒的画面基准，后面的图只做"造型/场景参考"。即使它忘了上一段，图1也能把0秒画面钉死。
- **为什么还要传角色/场景图**：图1只是某一帧，AI动起来后容易把脸画歪、把场景画错；再传定妆图和场景图，是给它"脸长这样、场景长这样"的硬锚点。

## 三、串行工作流（必须按顺序，不能跳）

```
1. 准备好 A、B、C1~Cn 固定资产图，和 F0 首帧构图图
2. 生成段1 → 下载成片 → 抽最后一帧存为 F1
3. 按"段2上传清单"传 F1 + A + C1 → 生成段2 → 抽尾帧存为 F2
4. 传 F2 + A + C1 → 生成段3 → 抽尾帧存为 F3
...一直到最后一段
```

**每段生成完立刻抽尾帧，别攒着**——不然会忘记哪段对应哪帧。

## 四、逐段 Seedance 标准提示词（九段式）

每段提示词按以下九个字段生成，字段内"{}"替换为分镜表内容：

```Plain Text
【风格】{已确认画风}，{该段时长}秒，16:9横屏，{该段剧情氛围}，电影级质感光影，超高细节，漫剧叙事。
【0秒基准】视频第0秒画面必须100%复刻图1的构图、人物姿态、机位、光影色调，作为整段起点。（非段1：承接上一段尾帧画面，无缝衔接，杜绝跳变）
【人物】图2是{角色名}的定妆参考，全段其脸、发型、服装、五官、脸型、配饰必须与图2完全一致，禁止AI改脸、换衣服、换发型。（多角色时逐一对应图号）
【场景】图{编号}是{场景名}场景参考，布局、光影、色调必须与图{编号}一致。（多场景逐一对应）
【时间轴】0-{时长}秒：{景别}，机位{精准坐标}，{焦段}，{适配剧情情绪的运镜}，{完整场景光影环境}；{角色动作表演全程}；{台词及口型}；{音效}。
【声音】{BGM设置（默认无BGM无配乐）}；环境音效：{全部音效}；对白情绪贴合剧情，口型与台词完全同步。
【镜头】{本段运镜描述}，稳定高级克制，无剧烈抖动；同场景衔接丝滑；跨场景采用末帧续接逻辑；背景按需虚化，不遮挡主体。
【禁区】无水印、无乱码、无logo、无任何字幕弹幕文字；无脸崩、无畸形肢体、无悬浮手、无多头多肢；禁止真人/Q版画风；全程光影统一；跨场景光影衔接自然；手机/屏幕只亮不渲染文字。
【参考图】图1={首帧/尾帧}（0秒基准），图2={角色}，图3={角色或场景}，图4={场景}（按实际上传顺序编写）
```

### 关键规则

- **无`@图片`资产时**：删除所有资产锁定语句，人物外观改用剧本文本描述，不开启资产锁定。
- **同场景多镜头**：每段必须写明"承接上一镜头光影、色调、人物姿态"。
- **跨场景切换**：必须自动植入"本段新场景严格继承上一段视频最后一帧的人物姿态、镜头视角、光影基调，平滑过渡进入新场景，无画面重启、无人物跳变"。
- **运镜按剧情情绪选择**：平静对话固定/微慢推，情绪波动轻拉/小幅平移，冲突震惊小幅摇镜/短促切镜。
- **手机/电脑屏幕**：统一写"屏幕亮起但不渲染任何文字"，从根上避免 AI 渲染乱码聊天文字。
- **牌匾/海报等**：如需留白写"保持空白不写字"。

## 五、成品文档四件套结构

1. **最终方案汇总**（资产绑定/画风/场景氛围/时长画幅/运镜/声音）
2. **固定资产图清单 + 每段上传图清单 + 串行工作流**
3. **逐段 Seedance 完整提示词**（九段式，每段标注上传顺序）
4. **避坑优化要点**

### 避坑优化要点（每次交付必附）

1. **每段都是新生成，不要指望它记得上一段**：每段都要按上传顺序把图1（尾帧）+ 角色图 + 场景图传齐，少传一张就会脸崩/场景飘。
2. **图1永远是上一段尾帧**：这是连贯性的命脉。生成完一段立刻抽尾帧，命名成 F1、F2……别搞混。
3. **Prompt 里的"图1/图2/图3/图4"和实际上传顺序一一对应**：上传时第一张选尾帧图，第二张选男主定妆图，第三张选女主或场景图，顺序乱了 AI 就会拿错图当首帧。
4. **无 BGM 无字幕**：每段【声音】里写死"无BGM无配乐"，画面也不许出任何文字。
5. **手机屏幕只亮不写字**：从根上避免 AI 渲染乱码聊天文字。
6. **串行生成**：不要并行跑多段，因为段 N+1 的首帧要靠段 N 生成完才能拿到。
